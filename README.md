# 📊 Trilha de 7 Dias em Análise de Dados - Vendas de Supermercado

Mini-projetos desenvolvidos para consolidação de habilidades em SQL e Power BI,
usando o dataset público Supermarket Sales (Kaggle).

## 🛠 Tecnologias
- SQL (MySQL 8): window functions, funções de data, CASE WHEN, LIKE, modelagem estrela.
- Power BI: dashboards, medidas DAX e modelagem de dados.
- Git & GitHub: versionamento e portfólio.

## 📅 Trilha

| Dia | Tema | Técnica | Status |

| 1 | Dashboard de vendas | SQL básico + Power BI | ✅ |
| 2 | Receita acumulada por cidade | Window functions + DAX | ✅ |
| 3 | Comportamento no tempo | Funções de data | ⬜ |
| 4 | Faixas de valor da compra | CASE WHEN | ⬜ |
| 5 | Análise de acessórios | LIKE | ⬜ |
| 6 | Modelo estrela (fato + dimensões) | Modelagem relacional | ⬜ |
| 7 | Painel final consolidado | Consolidação de portfólio | ⬜ |


## 📊 Dataset

(https://raw.githubusercontent.com/selva86/datasets/master/supermarket_sales.csv)
Vendas de um supermercado com 3 filiais (Yangon, Mandalay e Naypyitaw), registradas
entre janeiro e março de 2019.
